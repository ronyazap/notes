# COMP1238 - Midterm Notes

## Week 1 - History
- Writing systems developed long before modern computers.
- One writing system can be used for multiple languages.

## Week 2 - Bits and Bytes
- A bit represents either 0 or 1.
- One byte contains 8 bits.

## Week 3 - Text Encoding
- ASCII is a character encoding standard.
- Unicode supports characters from many languages.

## Week 4 - Command Line
- The `pwd` command displays the current working directory.
- The `ls` command lists files and directories.

## Week 5 - Command Line Tools
- SSH allows secure remote connections.
- SCP and SFTP can transfer files securely.
